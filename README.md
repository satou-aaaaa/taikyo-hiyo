# 退去費用だれが払う？

家具のへこみ、日焼け、鍵の交換…。賃貸の部屋を出るときの精算書（どれも架空）の4つの行から、本当は貸した人が払う行を見きわめる1日5問のゲーム。正解すると、なぜそうなるのかと、国の資料の出どころが出ます。

- 遊ぶ: https://satou-aaaaa.github.io/taikyo-hiyo/
- 今日の5問（やさしい2・ふつう2・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・ヒントなし）、練習（何度でも）、とことん（まちがえても続く。何問見きわめられるか）、見きわめたきまりが集まる「きまり帳」があります。
- 「こんなとき」の問題では、入居の日にすること・年数で減る負担・張替えの範囲・契約の特約・困ったときの相談先を選びます。
- 時間制限はありません。文字の大きさは3段から選べます。見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）もあります。
- 機種を変えるときは「引き継ぎ」で、記録をコードと QR にして移せます。

## 中身の出どころ

考え方は、次の公的な資料で確かめたことだけを使っています（2026-11-12 に確認）。部屋・人・会社はすべて架空です。

- 国土交通省「[原状回復をめぐるトラブルとガイドライン（再改訂版）](https://www.mlit.go.jp/common/001016469.pdf)」
- 国土交通省「[『原状回復をめぐるトラブルとガイドライン』の再改訂について](https://www.mlit.go.jp/report/press/house03_hh_000059.html)」
- 消費者庁「[消費者ホットライン 188](https://www.caa.go.jp/about_us/about/contact/)」

このゲームは考え方の練習で、法律の相談ではありません。実際の負担は契約の中身や部屋の様子で変わることがあります。困ったときは消費者ホットライン 188 に相談してください。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（問題と答えは入りません）。
